### Hi, I'm Cameron

I like building things and finding out whether they actually work. These days AI coding agents do most of the typing while I write the specs, make the calls, and check the results against real data.

Most of my time goes into [Gielinor Gains](https://www.gielinorgains.com), a flipping tool for Old School RuneScape that I build and run on my own. The code is private, but I write up what I test there, including the ideas that didn't pan out, on the [research](https://www.gielinorgains.com/research) and [What's New](https://www.gielinorgains.com/whats-new) pages.

Some other things I've made:

- [**Latent**](https://github.com/cameronspears/latent) turns a Sony A5100 into a film camera. Load a film stock, shoot the roll, develop it later.
- [**resume-hillclimb**](https://github.com/cameronspears/resume-hillclimb) is a Claude Code skill that improves a resume one change at a time and keeps a change only if blind judges prefer it.
- [**Pria 5**](https://github.com/cameronspears/pria-5) is a small two-way speaker I designed, 3D printed, measured and tuned at home, over more than 60 versions.
